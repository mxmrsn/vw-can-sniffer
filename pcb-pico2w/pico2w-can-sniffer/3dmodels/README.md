# Project 3D models

Two footprints use STEP files from this folder because the stock KiCad library has no model for them.

| Ref | Part | File | Source |
|---|---|---|---|
| J1 | Molex Pico-SPOX 87437-0473 | `874370473.stp` | Molex model via TraceParts; https://www.molex.com/en-us/products/part-detail/874370473 |
| S3 | C&K JS102011SAQN | `JS102011SAQN.step` | **Placeholder**, generated by `tools/make_placeholder_step.py` |

The S3 placeholder is two plain boxes. Its plan outline comes from the KiCad footprint (body 9.0 x 3.6 mm, actuator
1.5 mm wide protruding 2.0 mm past the body). The heights (body 3.5 mm, actuator 1.0-2.5 mm above the board) are
assumed, not taken from the datasheet. Check them against the datasheet or a real part before using this model for
an enclosure, or replace the file with the manufacturer's STEP under the same name.
