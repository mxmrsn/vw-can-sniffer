# Project 3D models

Two footprints look here for manufacturer STEP files that are not in the stock KiCad library:

| Ref | Part | Expected file | Source |
|---|---|---|---|
| J1 | Molex Pico-SPOX 87437-0473 | `874370473.stp` | https://www.molex.com/en-us/products/part-detail/874370473 → 3D Models and Design Files → `874370473_stp.zip` |
| S3 | C&K JS102011SAQN | `JS102011SAQN.step` | https://www.ckswitches.com/products/switches/product-details/Slide/JS/ → 3D model |

Unzip, rename to the expected file name, and put the file in this folder. J1 keeps the offset from the original
library footprint. S3's offset has not been checked against the C&K file and may need adjusting in the footprint's
3D Models tab.
